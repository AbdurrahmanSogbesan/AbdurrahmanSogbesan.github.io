# Portfolio

Abdurrahman Sogbesan's portfolio. Next.js (App Router) + TypeScript, statically exported to `out/`.

- `npm run dev`: local dev server
- `npm run build`: static export to `out/`
- `npm run lint` / `npm run typecheck` / `npm run format:check`

All copy lives in `content/`. Screenshots go in `public/screenshots/`; logos in `public/logos/`.

The résumé is a Google Drive link (`resumeUrl` in `content/site.ts`). To update it, upload a new version of the same
file in Drive (Manage versions) so the link doesn't change.
