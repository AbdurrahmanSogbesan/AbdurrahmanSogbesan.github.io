# Portfolio

Abdurrahman Sogbesan's portfolio. Next.js (App Router) + TypeScript, statically exported to `out/`.

- `npm run dev`: local dev server
- `npm run build`: static export to `out/`
- `npm run lint` / `npm run typecheck` / `npm run format:check`

All copy lives in `content/`. Assets to drop into `public/` later: `logos/`, `screenshots/`, `resume.pdf`.
