# TruePresence · detail screenshots

Drop images for /work/truepresence/ in this folder. PNG, JPG or WebP; numbering sets the order.

This is a phone project: every image renders as a 9:19.5 phone screen, three to a row.

- `hero-1.png`, `hero-2.png`, `hero-3.png` … go under the title (three fill one row).
- `gallery-1.png`, `gallery-2.png`, `gallery-3.png` … go after "What I did".

Export at 9:19.5 (e.g. 600×1300) so the screen fills its slot.

Only files that exist get a slot: an empty folder shows no screenshots on the page (no placeholders). Images are never cropped (object-fit: contain), so a different aspect ratio still shows whole, with the slot background around it. Rebuild after adding files.
