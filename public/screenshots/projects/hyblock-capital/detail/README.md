# Hyblock Capital · detail screenshots

Drop images for /work/hyblock-capital/ in this folder. PNG, JPG or WebP; numbering sets the order.

This is a web project: every image renders in a 16:10 slot.

- `hero-1.png` goes full width under the title (more hero files stack below it).
- `gallery-1.png`, `gallery-2.png` … go after "What I did", two per row (one per row on phones).

Export at 16:10 (e.g. 1600×1000) so the image fills its slot.

Only files that exist get a slot: an empty folder shows no screenshots on the page (no placeholders). Images are never cropped (object-fit: contain), so a different aspect ratio still shows whole, with the slot background around it. Rebuild after adding files.
